Hizmet Şartları

Söz Bot, kullanıcıların yetkilendirdiği kaynaklardan izin verilen içerikleri düzenleyerek Telegram üzerinde söz kategorileri oluşturur.

Kullanıcılar yalnızca kullanma hakkına sahip oldukları içerikleri yetkilendirmelidir.

Platformların kullanım şartları ve API kurallarına uyulur. Yetkisiz erişim veya güvenlik önlemlerini aşma amacıyla kullanım yasaktır.
